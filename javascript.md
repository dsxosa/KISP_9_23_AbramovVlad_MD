# Введение в JavaScript

***Что такое JavaScript?***

**JavaScript (JS)** — язык программирования, созданный для добавления интерактивности веб-страницам. Программы на нём называются *скриптами* и могут выполняться прямо в браузере без предварительной компиляции разработчиком.

- JavaScript изначально назывался LiveScript.
- JavaScript не является разновидностью Java — это самостоятельный язык.
- Его стандарт называется [ECMAScript](https://ru.wikipedia.org/wiki/ECMAScript).
- Сегодня JavaScript используется в браузерах, на серверах и мобильных устройствах.

***Движки JavaScript***

**Движок JavaScript** — программа, которая читает, преобразует и выполняет JavaScript-код.

Примеры движков:

- [V8](https://ru.wikipedia.org/wiki/V8_(движок_JavaScript)) — Chrome, Opera, Edge.
- [SpiderMonkey](https://ru.wikipedia.org/wiki/SpiderMonkey) — Firefox.
- JavaScriptCore — Safari.

**Как работает движок:**
1. Читает и анализирует код.
2. Преобразует его в машинный код.
3. Выполняет код и оптимизирует его работу.

***Что может JavaScript в браузере?***

JavaScript позволяет взаимодействовать с веб-страницами и пользователем.

Основные возможности:

- Изменять HTML-содержимое и CSS-стили страницы.
- Реагировать на действия пользователя: клики, движения мыши и нажатия клавиш.
- Отправлять и получать данные с сервера.
- Показывать сообщения и взаимодействовать с пользователем.
- Сохранять данные в браузере с помощью Local Storage.
- Работать с файлами и устройствами при наличии разрешения пользователя.

***Чего не может JavaScript в браузере?***

Для безопасности пользователей браузеры ограничивают возможности JavaScript.

Основные ограничения:

- Нельзя свободно читать, изменять и запускать файлы на компьютере.
- Нельзя получать доступ к камере и микрофону без разрешения пользователя.
- Нельзя свободно получать данные из других вкладок и сайтов.
- Доступ к данным других доменов ограничен правилами безопасности.

**Same Origin Policy (политика одинакового источника)** — правило безопасности, ограничивающее взаимодействие между ресурсами с разных источников (доменов, протоколов или портов).

Вне браузера, например в Node.js, действуют другие ограничения и доступны дополнительные возможности.

***Что делает JavaScript особенным?***

Главные преимущества JavaScript:

- Полная интеграция с HTML и CSS.
- Простота выполнения распространённых задач.
- Поддержка всеми основными браузерами.
- Не требует отдельной установки для запуска в браузере.

JavaScript широко используется для создания интерактивных интерфейсов, серверных и мобильных приложений.

***Языки над JavaScript***

**Транспиляция** — преобразование кода из одного языка программирования в другой, например в JavaScript.

Примеры языков:

- [TypeScript](https://www.typescriptlang.org/) — добавляет строгую типизацию.
- [CoffeeScript](https://coffeescript.org/) — предлагает более короткий и удобный синтаксис.
- [Flow](https://flow.org/) — добавляет проверку типов.
- [Dart](https://dart.dev/) — язык, который используется в том числе для разработки мобильных приложений.
- [Brython](https://brython.info/) — позволяет использовать Python для создания приложений, работающих в браузере через JavaScript.

Даже при использовании этих языков важно знать JavaScript, чтобы понимать работу программы.

***Итого***

- **JavaScript** — язык программирования для создания интерактивных приложений.
- Изначально предназначался для браузеров, но сейчас используется на разных платформах.
- Работает совместно с HTML и CSS.
- Выполняется специальными движками, например V8 и SpiderMonkey.
- Возможности JavaScript в браузере ограничены ради безопасности.
- Другие языки, например TypeScript, могут преобразовываться в JavaScript.

# Справочники и спецификации

***Спецификация JavaScript***

**Спецификация ECMA-262** — официальный документ, который подробно описывает правила и устройство языка JavaScript.

- [ECMA-262](https://www.ecma-international.org/publications-and-standards/standards/ecma-262/) — основная спецификация JavaScript.
- [Черновик спецификации](https://tc39.es/ecma262/) — содержит ещё не опубликованные официально изменения.
- [TC39 Proposals](https://github.com/tc39/proposals) — предложения по добавлению новых возможностей языка.

Спецификация является самым точным источником информации, но из-за сложного формального языка больше подходит для опытных разработчиков.

***Справочники***

**MDN JavaScript Reference** — справочник с подробной информацией о функциях, методах и встроенных объектах JavaScript.

- [MDN JavaScript Reference](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference) — документация с объяснениями и примерами.

Подходит для быстрого поиска информации и изучения возможностей языка.

***Таблицы совместимости***

Таблицы совместимости помогают узнать, какие возможности JavaScript поддерживаются разными браузерами и движками.

Основные ресурсы:

- [Can I Use](https://caniuse.com/) — показывает поддержку технологий и функций в браузерах.
- [Kangax Compatibility Table](https://kangax.github.io/compat-table/) — показывает, какие возможности JavaScript поддерживаются разными движками.

***Итого***

- **ECMA-262** — официальное описание языка JavaScript.
- **MDN** — справочник по функциям, методам и возможностям языка.
- **Can I Use** и **Kangax** — проверка совместимости с браузерами.
- Эти ресурсы помогают находить точную информацию и проверять поддержку возможностей JavaScript.

# Редакторы кода

Редакторы кода — программы для написания и изменения программного кода. Существуют два основных типа:

***IDE***

**IDE** — интегрированная среда разработки, предназначенная для работы с целыми проектами.

Основные возможности:
- Автодополнение и проверка кода.
- Поиск ошибок и отладка.
- Работа с файлами проекта.
- Интеграция с Git.

Примеры: **Visual Studio Code, WebStorm**.

***Лёгкие редакторы***

Предназначены преимущественно для быстрого открытия и редактирования отдельных файлов.

Особенности:
- Быстрый запуск.
- Простой интерфейс.
- Небольшая нагрузка на компьютер.
- Возможность установки дополнительных плагинов.

Примеры: **Notepad++, Sublime Text, Vim**.

***Выбор редактора***

Выбор зависит от задач и личных предпочтений разработчика.

# Консоль разработчика

**Инструменты разработчика (DevTools)** — встроенные инструменты браузера, которые помогают находить ошибки, проверять код и выполнять JavaScript-команды.

***Консоль (Console)***

Консоль позволяет:
- Просматривать ошибки JavaScript.
- Узнавать номер строки, в которой произошла ошибка.
- Вводить и выполнять JavaScript-код.
- Проверять значения переменных.

**Основные клавиши:**
- `F12` — открыть DevTools в большинстве браузеров.
- `Cmd + Opt + J` — открыть консоль в Chrome на Mac.
- `Cmd + Opt + C` — открыть консоль в Safari на Mac.

***Работа с консолью***

- `Enter` — выполнить введённую команду.
- `Shift + Enter` — перейти на новую строку без выполнения кода.
- Ошибки обычно отображаются красным цветом, рядом указывается место их возникновения.

***Другие браузеры***

Инструменты разработчика есть практически во всех современных браузерах: Chrome, Firefox, Edge и Safari.

В Safari на Mac сначала необходимо включить **меню разработчика** в настройках браузера.

***Итого***

- DevTools помогают находить и исправлять ошибки в коде.
- Вкладка **Console** используется для просмотра ошибок и выполнения JavaScript-команд.
- В большинстве браузеров инструменты разработчика открываются клавишей `F12`.
- Принципы работы консоли в разных браузерах практически одинаковы.

Полезная ссылка: [Инструменты разработчика в браузере](https://learn.javascript.ru/devtools).

# Основы JavaScript

***Привет, мир!***

JavaScript можно запускать в браузере или через Node.js. В этой главе изучаются основные возможности самого языка.

***Структура кода***

**Инструкции** — команды, которые выполняет JavaScript. Обычно каждая инструкция пишется с новой строки.

**Точка с запятой** `;` используется для разделения инструкций. JavaScript может автоматически добавлять её в некоторых случаях, но рекомендуется ставить точку с запятой самостоятельно.

**Комментарии** нужны для пояснения кода и не выполняются программой.

```javascript
// Однострочный комментарий

/*
Многострочный
комментарий
*/
```

***Строгий режим — `use strict`***

Строгий режим помогает избегать ошибок и использовать более безопасный синтаксис JavaScript.

Включается директивой `"use strict"` в начале скрипта:

```javascript
"use strict";

// Код в строгом режиме
```

- Директива должна находиться в начале скрипта.
- После включения строгий режим нельзя отключить.
- В современных модулях и классах он включён автоматически.

***Подключение JavaScript к HTML***

Для добавления JavaScript в HTML используется тег `<script>`.

```html
<script>
  alert("Привет, мир!");
</script>
```

Также можно подключить отдельный файл:

```html
<script src="script.js"></script>
```

Внешние скрипты удобнее хранить отдельно от HTML. Браузер может кешировать их, благодаря чему повторная загрузка становится быстрее.

***Переменные***

**Переменная** — именованное хранилище для данных. Для создания переменных используются `let`, `const` и `var`.

**Создание и изменение переменных**

```javascript
let message = "Привет";
message = "Пока";

const age = 18;
```

- `let` — создаёт переменную, значение которой можно менять.
- `const` — создаёт константу, которую нельзя переназначить.
- `var` — старый способ объявления переменных, обычно не рекомендуется.

Повторно объявить переменную через `let` в одной области видимости нельзя.

**Правила именования переменных**

- Имя может содержать буквы, цифры, `$` и `_`.
- Не должно начинаться с цифры.
- Регистр имеет значение: `age` и `Age` — разные переменные.
- Нельзя использовать зарезервированные слова JavaScript.
- Обычно используют стиль `camelCase`, например `userName`.
- Желательно давать понятные имена, отражающие назначение переменной.

**Константы**

`const` используется для значений, которые не должны переназначаться.

Для заранее известных постоянных значений иногда используют заглавные буквы и `_`:

```javascript
const COLOR_RED = "#F00";
```

Для обычных констант, значение которых определяется во время работы программы, используют `camelCase`.

**Правила работы с переменными**

- Всегда объявляйте переменные через `let`, `const` или `var`.
- Не создавайте переменные простым присваиванием без объявления.
- Не используйте одну переменную для совершенно разных задач без необходимости.
- Используйте `const`, если значение не нужно менять.

***Типы данных***

В JavaScript существует **8 основных типов данных**. Язык является динамически типизированным: переменная может хранить данные разных типов, и её тип может меняться.

```javascript
let message = "Привет";
message = 123; // Ошибки нет
```

**Число (`number`)**

Используется для целых и дробных чисел. Поддерживает математические операции: `+`, `-`, `*`, `/`.

Особые числовые значения:
- `Infinity` и `-Infinity` — бесконечность.
- `NaN` — результат некорректной математической операции.

```javascript
alert(1 / 0); // Infinity
alert("текст" / 2); // NaN
```

**Большие числа (`BigInt`)**

Позволяет работать с очень большими целыми числами, выходящими за безопасный диапазон `number`.

Для создания в конце числа добавляется `n`.

```javascript
const bigNumber = 12345678901234567890n;
```

**Строка (`string`)**

Используется для хранения текста. Есть три вида кавычек:
- `"..."` — двойные;
- `'...'` — одинарные;
- `` `...` `` — обратные.

Обратные кавычки позволяют вставлять переменные и выражения через `${}`.

```javascript
let name = "Иван";
alert(`Привет, ${name}!`);
```

Отдельного типа для одного символа нет — используется `string`.

**Логический тип (`boolean`)**

Имеет только два значения:
- `true` — истина;
- `false` — ложь.

Используется для проверок и условий.

```javascript
let isAdult = true;
let isGreater = 5 > 3; // true
```

**Значение `null`**

Обозначает отсутствие значения, пустоту или неизвестное значение.

```javascript
let age = null;
```

**Значение `undefined`**

Означает, что переменной не присвоено значение.

```javascript
let age;
alert(age); // undefined
```

Обычно `null` используют для обозначения пустого значения, а `undefined` — когда значение ещё не задано.

**Объекты (`object`) и символы (`symbol`)**

- `object` — хранит коллекции данных и сложные структуры.
- `symbol` — создаёт уникальные идентификаторы.

Первые семь типов считаются **примитивными**, а `object` является отдельным типом.

**Оператор `typeof`**

Позволяет определить тип значения. Возвращает строку с названием типа.

```javascript
typeof 123;       // "number"
typeof "Привет";  // "string"
typeof true;      // "boolean"
typeof undefined; // "undefined"
typeof 10n;       // "bigint"
```

Особенности:
- `typeof null` возвращает `"object"` — это историческая ошибка JavaScript.
- `typeof alert` возвращает `"function"`.

**Итого: 8 типов данных**

1. `number` — числа.
2. `bigint` — большие целые числа.
3. `string` — строки.
4. `boolean` — логические значения.
5. `null` — отсутствие или неизвестность значения.
6. `undefined` — значение не присвоено.
7. `symbol` — уникальные идентификаторы.
8. `object` — сложные структуры данных.

Оператор `typeof` используется для проверки типа данных.

***Взаимодействие: alert, prompt, confirm***

В браузере JavaScript может взаимодействовать с пользователем с помощью трёх функций.

**`alert`**

Показывает сообщение и ждёт нажатия кнопки «ОК».

```javascript
alert("Привет!");
```

**`prompt`**

Показывает окно с сообщением и полем для ввода текста.

```javascript
let age = prompt("Сколько тебе лет?", 18);
```

- Первый аргумент — текст сообщения.
- Второй аргумент — необязательное значение по умолчанию.
- Возвращает введённый текст или `null`, если пользователь отменил ввод.

**`confirm`**

Показывает вопрос с кнопками «ОК» и «Отмена».

```javascript
let isBoss = confirm("Ты здесь главный?");
```

Возвращает:
- `true` — если нажата кнопка «ОК»;
- `false` — если нажата кнопка «Отмена».

**Особенности**

Все три функции открывают **модальные окна**. Пока окно открыто, пользователь не может взаимодействовать с остальной страницей, а выполнение скрипта приостанавливается.

Внешний вид и расположение окон определяются браузером — изменить их нельзя.

# Преобразование типов

JavaScript автоматически преобразует значения к нужному типу при выполнении операций и функций. При необходимости можно выполнить преобразование вручную.

Существует **3 основных вида преобразования**: строковое, численное и логическое.

***Строковое преобразование***

Преобразует значение в строку (`string`). Используется, например, функцией `alert()`.

Для явного преобразования применяется `String(value)`.

```javascript
let value = true;
value = String(value);

alert(value); // "true"
```

Основные значения преобразуются очевидным образом: `false` → `"false"`, `null` → `"null"`.

***Численное преобразование***

Преобразует значение в число (`number`). Автоматически происходит в математических операциях.

Для явного преобразования используется `Number(value)`.

```javascript
let str = "123";
let num = Number(str);

alert(num); // 123
```

Если строку невозможно преобразовать в число, результатом будет `NaN`.

**Основные правила преобразования:**

| Значение | Результат |
|---|---|
| `undefined` | `NaN` |
| `null` | `0` |
| `true` | `1` |
| `false` | `0` |
| `""` и строки из пробелов | `0` |
| Строка с числом | Число |
| Некорректная строка | `NaN` |

```javascript
Number("123");  // 123
Number("123z"); // NaN
Number(true);   // 1
Number(null);   // 0
```

***Логическое преобразование***

Преобразует значение в логический тип (`boolean`). Для явного преобразования используется `Boolean(value)`.

**Правила преобразования:**

- `0`, `null`, `undefined`, `NaN` и пустая строка `""` превращаются в `false`.
- Все остальные значения превращаются в `true`.

```javascript
Boolean(1);       // true
Boolean(0);       // false
Boolean("Привет"); // true
Boolean("");      // false
```

**Важно:**
- Строка `"0"` преобразуется в `true`, потому что она непустая.
- Строка из пробелов `" "` тоже преобразуется в `true`.

***Итого***

В JavaScript есть три основных преобразования:

- **Строковое** — `String(value)`, преобразует значение в строку.
- **Численное** — `Number(value)`, преобразует значение в число.
- **Логическое** — `Boolean(value)`, преобразует значение в `true` или `false`.

Особенно важно запомнить:
- `Number(undefined)` → `NaN`, а `Number(null)` → `0`.
- `Boolean("0")` и `Boolean(" ")` → `true`.

Преобразование объектов в примитивные значения рассматривается отдельно: [Преобразование объектов в примитивы](https://learn.javascript.ru/object-toprimitive).

# Базовые операторы, математика

Операторы позволяют выполнять математические действия, сравнения и другие операции над значениями.

***Термины: «унарный», «бинарный», «операнд»***

- **Операнд** — значение, к которому применяется оператор.
- **Унарный оператор** — работает с одним операндом. Например, `-x` меняет знак числа.
- **Бинарный оператор** — работает с двумя операндами. Например, `x - y` вычитает одно число из другого.

```javascript
let x = 1;
let y = 3;

alert(-x); // -1
alert(y - x); // 2
```

***Математика***

Основные математические операторы JavaScript:

| Оператор | Действие |
|---|---|
| `+` | Сложение |
| `-` | Вычитание |
| `*` | Умножение |
| `/` | Деление |
| `%` | Остаток от деления |
| `**` | Возведение в степень |

**Остаток от деления `%`**

Возвращает остаток после деления одного числа на другое.

```javascript
5 % 2; // 1
8 % 3; // 2
8 % 4; // 0
```

**Возведение в степень `**`**

Возводит число в указанную степень.

```javascript
2 ** 3; // 8
4 ** (1/2); // 2 (квадратный корень)
```

***Сложение строк при помощи бинарного `+`***

Если хотя бы один операнд является строкой, оператор `+` преобразует второй операнд в строку и объединяет их.

```javascript
"Привет, " + "мир!"; // "Привет, мир!"
"1" + 2; // "12"
2 + 2 + "1"; // "41"
```

Остальные математические операторы (`-`, `*`, `/` и другие) преобразуют значения в числа.

```javascript
6 - "2"; // 4
"6" / "2"; // 3
```

***Приведение к числу, унарный `+`***

Унарный плюс `+` преобразует значение в число. Для чисел он ничего не меняет. Работает аналогично `Number()`.

```javascript
+true; // 1
+""; // 0
+"123"; // 123
```

Полезен при работе со строками, например при получении данных из HTML-форм.

```javascript
let apples = "2";
let oranges = "3";

alert(+apples + +oranges); // 5
```

Без унарного плюса бинарный `+` объединил бы строки и вернул `"23"`.

***Приоритет операторов***

Если в выражении несколько операторов, порядок их выполнения определяется **приоритетом**. Чем выше приоритет, тем раньше выполняется операция.

```javascript
1 + 2 * 2; // 5
(1 + 2) * 2; // 6
```

Скобки позволяют изменить порядок выполнения операций.

Полную таблицу можно посмотреть в [справочнике приоритетов операторов](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Operators/Operator_Precedence).

***Присваивание***

Оператор `=` записывает значение в переменную. Он имеет низкий приоритет, поэтому сначала выполняются математические операции.

```javascript
let x = 2 * 2 + 1; // 5
```

**Присваивание возвращает значение**

Оператор присваивания не только записывает значение, но и возвращает его. Поэтому его можно использовать внутри выражений.

```javascript
let a = 1;
let b = 2;

let c = 3 - (a = b + 1);
```

Такие конструкции лучше не использовать без необходимости, чтобы код оставался понятным.

**Присваивание по цепочке**

Несколько переменных можно присвоить одному значению. Вычисление происходит справа налево.

```javascript
let a, b, c;

a = b = c = 4;
```

Для лучшей читаемости рекомендуется разделять присваивания на отдельные строки.

***Сокращённая арифметика с присваиванием***

Позволяет выполнить операцию и записать результат в ту же переменную.

| Оператор | Пример | Аналог |
|---|---|---|
| `+=` | `n += 2` | `n = n + 2` |
| `-=` | `n -= 2` | `n = n - 2` |
| `*=` | `n *= 2` | `n = n * 2` |
| `/=` | `n /= 2` | `n = n / 2` |
| `**=` | `n **= 2` | `n = n ** 2` |

```javascript
let n = 2;
n += 5; // 7
n *= 2; // 14
```

***Инкремент и декремент***

- **Инкремент `++`** — увеличивает переменную на 1.
- **Декремент `--`** — уменьшает переменную на 1.

```javascript
let counter = 2;
counter++; // 3
counter--; // 2
```

Операторы имеют две формы:

- **Префиксная** — `++counter`: сначала изменяет значение, затем возвращает новое.
- **Постфиксная** — `counter++`: сначала возвращает старое значение, затем изменяет его.

```javascript
let counter = 1;

alert(++counter); // 2

counter = 1;
alert(counter++); // 1
```

Если возвращаемое значение не используется, разницы между формами нет.

**Важно:** `++` и `--` применяются только к переменным. Не рекомендуется использовать их внутри сложных выражений — лучше записывать каждое действие отдельно.

***Побитовые операторы***

Работают с числами на уровне их двоичного представления (32-разрядные целые числа).

Основные операторы:

| Оператор | Назначение |
|---|---|
| `&` | AND (И) |
| `|` | OR (ИЛИ) |
| `^` | XOR (исключающее ИЛИ) |
| `~` | NOT (НЕ) |
| `<<` | Сдвиг влево |
| `>>` | Сдвиг вправо |
| `>>>` | Сдвиг вправо с заполнением нулями |

Используются редко, в основном при работе с данными на низком уровне. Подробнее: [Побитовые операторы](https://learn.javascript.ru/bitwise-operators).

***Оператор «запятая»***

Оператор `,` позволяет выполнить несколько выражений подряд, но возвращает только результат последнего.

```javascript
let a = (1 + 2, 3 + 4);

alert(a); // 7
```

У оператора запятой очень низкий приоритет, поэтому для правильного порядка вычислений часто нужны скобки.

Обычно его используют редко, так как несколько действий в одной строке могут ухудшить читаемость кода.

# Операторы сравнения

***Основные операторы***

- `>` — больше.
- `<` — меньше.
- `>=` — больше или равно.
- `<=` — меньше или равно.
- `==` — нестрогое равенство.
- `!=` — нестрогое неравенство.
- `===` — строгое равенство.
- `!==` — строгое неравенство.

**Результат сравнения** всегда имеет логический тип: `true` или `false`.

```javascript
alert(5 > 4); // true

let result = 2 == 1;
alert(result); // false
```

***Сравнение строк***

Строки сравниваются посимвольно в **лексикографическом порядке** (по кодам Unicode):

1. Сравниваются первые символы.
2. Если они равны — следующие.
3. Если одна строка закончилась раньше, она считается меньшей.

Регистр имеет значение: строчные и заглавные буквы имеют разные коды Unicode.

```javascript
alert('Коты' > 'Кода'); // true
alert('Я' > 'А'); // true
```

***Сравнение разных типов***

При нестрогом сравнении `==` и математических сравнениях значения разных типов могут преобразовываться к числам.

- Строка с числом преобразуется в число: `'2' > 1` → `true`.
- `true` преобразуется в `1`, а `false` — в `0`.
- Поэтому `0 == false` и `'01' == 1` возвращают `true`.

***Строгое сравнение***

Операторы `===` и `!==` сравнивают значения **без приведения типов**.

```javascript
alert(0 == false);  // true
alert(0 === false); // false
```

Рекомендуется использовать `===` и `!==`, поскольку они помогают избежать ошибок из-за автоматического преобразования типов.

***Сравнение с null и undefined***

Особые правила:

- `null === undefined` → `false` (разные типы).
- `null == undefined` → `true` (специальное правило языка).
- При числовом преобразовании `null` становится `0`, а `undefined` — `NaN`.
- `undefined` не равен никакому значению, кроме `null` при использовании `==`.

**Особенности сравнений:**

```javascript
alert(null > 0);  // false
alert(null == 0); // false
alert(null >= 0); // true

alert(undefined > 0);  // false
alert(undefined < 0);  // false
alert(undefined == 0); // false
```

`NaN` возвращает `false` при любых сравнениях с помощью `>`, `<`, `>=`, `<=`.

***Как избежать ошибок***

- Используйте `===` и `!==` вместо `==` и `!=`.
- Будьте осторожны при сравнении с `null` и `undefined`.
- Если переменная может содержать `null` или `undefined`, проверяйте эти значения отдельно, прежде чем использовать операторы `>`, `<`, `>=`, `<=`.

***Итого***

- Сравнения возвращают `true` или `false`.
- Строки сравниваются посимвольно по Unicode.
- При нестрогом сравнении возможно автоматическое преобразование типов.
- `===` и `!==` сравнивают без преобразования типов.
- `null == undefined` возвращает `true`, но с другими значениями они не равны.
- Сравнения с `null` и `undefined` требуют осторожности.

# Условное ветвление: if, '?'

***Инструкция if***

`if` проверяет условие и выполняет блок кода, если результат `true`.

```javascript
if (year == 2015) {
  alert('Правильно!');
  alert('Вы такой умный!');
}
```

Рекомендуется всегда использовать фигурные скобки `{}`, даже если внутри только одна инструкция.

***Преобразование к логическому типу***

Условие в `if` автоматически преобразуется к типу `Boolean`.

**Ложные (falsy) значения:**
- `0`;
- `""` (пустая строка);
- `null`;
- `undefined`;
- `NaN`.

Все остальные значения считаются истинными (truthy).

```javascript
if (0) {
  // Не выполнится
}

if (1) {
  // Выполнится
}
```

***Блоки else и else if***

- `else` выполняется, если условие `if` ложно.
- `else if` позволяет проверить дополнительные условия.
- Блоков `else if` может быть несколько, а `else` необязателен.

```javascript
if (year < 2015) {
  alert('Слишком рано');
} else if (year > 2015) {
  alert('Слишком поздно');
} else {
  alert('Верно!');
}
```

***Условный оператор '?'***

Условный оператор `?` (тернарный оператор) позволяет выбрать одно из двух значений в зависимости от условия.

**Синтаксис:**

```javascript
let result = условие ? значение1 : значение2;
```

Если условие истинно, возвращается `значение1`, иначе — `значение2`.

```javascript
let age = 20;
let accessAllowed = age > 18 ? true : false;
```

Если само условие уже возвращает `true` или `false`, оператор можно упростить:

```javascript
let accessAllowed = age > 18;
```

***Несколько операторов '?'***

Можно объединять несколько тернарных операторов для проверки нескольких условий:

```javascript
let age = 20;

let message = (age < 3) ? 'Малыш' :
  (age < 18) ? 'Привет!' :
  (age < 100) ? 'Здравствуйте!' :
  'Необычный возраст!';
```

Однако для нескольких ветвей `if...else` обычно читается понятнее.

***Когда использовать if, а когда '?'***

- `if...else` — когда нужно выполнить разные блоки кода.
- `?` — когда нужно выбрать и вернуть одно из значений в зависимости от условия.

Не рекомендуется использовать `?` вместо `if` для выполнения разных инструкций: такой код сложнее читать.

***Итого***

- `if` выполняет код, если условие истинно.
- `else` выполняется, если условие ложно.
- `else if` проверяет дополнительные условия.
- Условия автоматически преобразуются к `Boolean`.
- `?` выбирает одно из двух значений.
- Для выполнения разных блоков кода используйте `if`, для выбора значения — `?`.

# Логические операторы

В JavaScript есть логические операторы:

- `||` — ИЛИ.
- `||=` — логическое присваивание ИЛИ.
- `&&` — И.
- `&&=` — логическое присваивание И.
- `!` — НЕ.

Операторы могут работать со значениями любых типов, а не только с `true` и `false`.

***Оператор ИЛИ `||`***

Возвращает `true`, если хотя бы одно условие истинно. Если оба ложные — возвращает `false`.

```javascript
alert(true || false); // true
alert(false || false); // false
```

При работе с любыми типами `||` возвращает **первое истинное значение**, а если все значения ложные — последнее.

```javascript
alert(null || 1); // 1
alert(0 || "Привет"); // "Привет"
alert(null || 0); // 0
```

**Сокращённое вычисление:** оператор прекращает проверку, как только находит первое истинное значение. Остальные операнды не вычисляются.

```javascript
true || alert("Не выполнится");
false || alert("Выполнится");
```

Часто `||` используют, чтобы получить первое доступное значение или значение по умолчанию:

```javascript
let userName = "" || "Аноним";
```

***Логическое присваивание ИЛИ `||=`***

Присваивает переменной новое значение, только если её текущее значение ложное (`falsy`).

```javascript
let userName = "";

userName ||= "Аноним";

alert(userName); // "Аноним"
```

Примерная логика оператора:

```javascript
a || (a = b);
```

***Оператор И `&&`***

Возвращает `true`, только если оба условия истинны. Если хотя бы одно ложно — возвращает `false`.

```javascript
alert(true && true); // true
alert(true && false); // false
```

При работе с любыми типами `&&` возвращает **первое ложное значение**, а если все значения истинные — последнее.

```javascript
alert(1 && 0); // 0
alert(null && 5); // null
alert(1 && 2 && 3); // 3
```

**Сокращённое вычисление:** оператор прекращает проверку, когда находит первое ложное значение.

Приоритет `&&` выше, чем у `||`. Поэтому сначала выполняется И, затем ИЛИ.

```javascript
a && b || c && d;

// Аналогично:
(a && b) || (c && d);
```

Не рекомендуется заменять `if` оператором `&&`, даже если запись получается короче. Для выполнения условий лучше использовать `if`.

***Логическое присваивание И `&&=`***

Присваивает переменной новое значение, только если её текущее значение истинное (`truthy`).

```javascript
let greeting = "Привет";

greeting &&= greeting + ", пользователь!";

alert(greeting); // "Привет, пользователь!"
```

Примерная логика оператора:

```javascript
a && (a = b);
```

***Оператор НЕ `!`***

Преобразует значение к логическому типу и возвращает противоположное значение.

```javascript
alert(!true); // false
alert(!0); // true
```

**Двойное НЕ `!!`** используется для преобразования любого значения в `true` или `false`.

```javascript
alert(!!"Привет"); // true
alert(!!null); // false
```

То же самое можно сделать с помощью `Boolean()`:

```javascript
Boolean("Привет"); // true
Boolean(null); // false
```

Приоритет `!` выше, чем у `&&` и `||`, поэтому НЕ выполняется первым.

***Итого***

- `||` возвращает первое истинное значение или последнее, если все ложные.
- `||=` присваивает новое значение, если текущее ложное.
- `&&` возвращает первое ложное значение или последнее, если все истинные.
- `&&=` присваивает новое значение, если текущее истинное.
- `!` инвертирует логическое значение.
- `!!` преобразует значение в `true` или `false`.
- `&&` имеет более высокий приоритет, чем `||`.
- Логические операторы используют сокращённое вычисление: последующие операнды могут не выполняться.

# Операторы нулевого слияния и присваивания: `??`, `??=`

***Оператор нулевого слияния `??`***

Оператор `??` возвращает:

- Первое значение, если оно не `null` и не `undefined`.
- Второе значение, если первое равно `null` или `undefined`.

**Синтаксис:**

```javascript
result = a ?? b;
```

Чаще всего используется для задания значения по умолчанию.

```javascript
let user;

alert(user ?? "Аноним"); // "Аноним"

let name = "Иван";

alert(name ?? "Аноним"); // "Иван"
```

Можно объединять несколько операторов `??`, чтобы получить первое определённое значение:

```javascript
let firstName = null;
let lastName = null;
let nickName = "Суперкодер";

alert(firstName ?? lastName ?? nickName ?? "Аноним");
// "Суперкодер"
```

***Сравнение `??` и `||`***

Главное отличие:

- `||` возвращает первое истинное значение (`truthy`).
- `??` возвращает первое значение, которое не равно `null` или `undefined`.

```javascript
let height = 0;

alert(height || 100); // 100
alert(height ?? 100); // 0
```

`0`, `false` и `""` являются ложными значениями для `||`, но для `??` они считаются определёнными.

Поэтому используйте `??`, если значение по умолчанию нужно только при `null` или `undefined`.

***Приоритет и скобки***

У оператора `??` низкий приоритет. При использовании вместе с арифметическими операторами могут понадобиться скобки.

```javascript
let height = null;
let width = null;

let area = (height ?? 100) * (width ?? 50);

alert(area); // 5000
```

**Важно:** JavaScript запрещает использовать `??` вместе с `&&` или `||` без явных скобок.

```javascript
// Ошибка:
let x = 1 && 2 ?? 3;

// Правильно:
let x = (1 && 2) ?? 3;
```

***Оператор нулевого присваивания `??=`***

Оператор `??=` присваивает переменной новое значение, только если она равна `null` или `undefined`.

**Синтаксис:**

```javascript
x ??= y;
```

Пример:

```javascript
let userAge = null;

userAge ??= 18;

alert(userAge); // 18
```

Если переменная уже содержит определённое значение, присваивание не выполняется.

```javascript
let userAge = 18;

userAge ??= 21;

alert(userAge); // 18
```

Правая часть оператора `??=` вычисляется только тогда, когда переменная равна `null` или `undefined`.

***Итого***

- `??` возвращает первое значение, которое не равно `null` или `undefined`.
- `||` возвращает первое истинное значение.
- `0`, `false` и `""` сохраняются при использовании `??`.
- `??=` присваивает новое значение только при `null` или `undefined`.
- `??` нельзя использовать вместе с `&&` или `||` без скобок.
- Приоритет `??` низкий, поэтому в сложных выражениях используйте скобки.

# Циклы while и for

Циклы позволяют многократно выполнять один и тот же участок кода, пока выполняется определённое условие.

Одно выполнение тела цикла называется **итерацией**.

***Цикл while***

Цикл `while` выполняет код, пока условие истинно (`true`).

**Синтаксис:**

```javascript
while (condition) {
  // тело цикла
}
```

Пример:

```javascript
let i = 0;

while (i < 3) {
  alert(i);
  i++;
}
```

Результат: `0`, `1`, `2`.

Если условие изначально ложно, тело цикла не выполнится ни разу.

**Важно:** необходимо изменять переменную условия, иначе можно получить бесконечный цикл.

***Цикл do...while***

Похож на `while`, но сначала выполняет тело цикла, а потом проверяет условие.

**Синтаксис:**

```javascript
do {
  // тело цикла
} while (condition);
```

Пример:

```javascript
let i = 0;

do {
  alert(i);
  i++;
} while (i < 3);
```

Главное отличие: `do...while` гарантирует хотя бы одно выполнение тела цикла, даже если условие изначально ложно.

***Цикл for***

Самый распространённый цикл. Удобен, когда заранее известны условия повторения.

**Синтаксис:**

```javascript
for (начало; условие; шаг) {
  // тело цикла
}
```

Пример:

```javascript
for (let i = 0; i < 3; i++) {
  alert(i);
}
```

Результат: `0`, `1`, `2`.

**Части цикла:**

- **Начало** — выполняется один раз перед запуском цикла.
- **Условие** — проверяется перед каждой итерацией. Если `false`, цикл завершается.
- **Тело** — выполняется, пока условие истинно.
- **Шаг** — выполняется после каждой итерации.

**Переменная внутри цикла**

Если объявить переменную через `let` внутри `for`, она будет доступна только внутри цикла.

```javascript
for (let i = 0; i < 3; i++) {
  alert(i);
}

// alert(i); // Ошибка
```

Можно использовать переменную, объявленную заранее:

```javascript
let i = 0;

for (i = 0; i < 3; i++) {
  alert(i);
}

alert(i); // 3
```

**Пропуск частей for**

Любую часть цикла `for` можно пропустить. Например:

```javascript
let i = 0;

for (; i < 3; ) {
  alert(i++);
}
```

Если убрать все части, получится бесконечный цикл:

```javascript
for (;;) {
  // бесконечный цикл
}
```

Точки с запятой между частями `for` обязательны.

***Прерывание цикла — break***

`break` полностью прекращает выполнение цикла и передаёт управление коду после него.

```javascript
let i = 0;

while (true) {
  if (i == 3) break;

  alert(i);
  i++;
}
```

`break` часто используют, когда условие завершения находится внутри тела цикла.

***Переход к следующей итерации — continue***

`continue` пропускает оставшуюся часть текущей итерации и переходит к следующей.

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 == 0) continue;

  alert(i);
}
```

Результат: `1`, `3`, `5`, `7`, `9`.

`continue` удобно использовать, чтобы избежать лишней вложенности условий.

**Важно:** `break` и `continue` нельзя использовать внутри тернарного оператора `?`. Для таких случаев используйте обычный `if`.

***Метки для break и continue***

Метки позволяют управлять внешними циклами из внутренних.

**Синтаксис:**

```javascript
outer: for (...) {
  for (...) {
    if (condition) break outer;
  }
}
```

`break outer` завершает весь цикл с меткой `outer`, а не только внутренний.

`continue outer` переходит к следующей итерации внешнего цикла.

Метки используются редко, в основном во вложенных циклах, когда нужно выйти сразу из нескольких уровней.

***Итого***

- `while` — проверяет условие перед каждой итерацией.
- `do...while` — сначала выполняет код, затем проверяет условие. Выполняется минимум один раз.
- `for` — цикл с началом, условием и шагом.
- `break` — полностью завершает цикл.
- `continue` — пропускает текущую итерацию.
- Метки позволяют `break` и `continue` управлять внешними циклами.
- Следите за условием завершения, чтобы случайно не создать бесконечный цикл.

# Конструкция `switch`

`switch` — конструкция для сравнения одного выражения с несколькими вариантами. Может заменить несколько `if...else`.

***Синтаксис***

```javascript
switch (x) {
  case value1:
    // код
    break;

  case value2:
    // код
    break;

  default:
    // код, если совпадений нет
}
```

- `switch` последовательно сравнивает выражение с каждым `case` через **строгое равенство (`===`)**.
- При совпадении выполняется код соответствующего `case`.
- `break` завершает выполнение `switch`.
- `default` выполняется, если ни один `case` не подошёл. Он необязателен.

***Особенности `break`***

Если не поставить `break`, выполнение продолжится в следующих `case`, даже если их значения не совпадают. Это называется *проваливанием* (fall-through).

```javascript
let a = 2 + 2;

switch (a) {
  case 4:
    alert('Четыре');
  case 5:
    alert('Пять');
  default:
    alert('Другое значение');
}
```

Выполнятся все три `alert`, потому что после первого `case` нет `break`.

***Группировка `case`***

Несколько вариантов можно объединить, если для них нужен один код:

```javascript
switch (a) {
  case 3:
  case 5:
    alert('Неправильно');
    break;

  case 4:
    alert('Правильно');
    break;
}
```

***Выражения в `switch` и `case`***

В качестве аргументов можно использовать любые выражения — они вычисляются перед сравнением.

```javascript
let a = "1";
let b = 0;

switch (+a) {
  case b + 1:
    alert('Совпадение');
    break;
}
```

***Тип имеет значение***

Сравнение выполняется строго (`===`), поэтому значения разных типов не совпадают.

```javascript
let arg = prompt('Введите число?');

switch (arg) {
  case '3':
    alert('Строка 3');
    break;

  case 3:
    alert('Число 3');
    break;
}
```

`prompt()` возвращает строку, поэтому ввод `3` соответствует `case '3'`, но не `case 3`.

# Функции

Функции — основные строительные блоки программы. Они позволяют объединять код в отдельные части и повторно использовать его, избегая дублирования.

***Объявление функции***

Функция создаётся с помощью `function`:

```javascript
function showMessage() {
  alert('Всем привет!');
}

showMessage(); // вызов функции
```

- `function` — ключевое слово для объявления функции.
- `showMessage` — имя функции.
- `()` — параметры (могут отсутствовать).
- `{}` — тело функции с выполняемым кодом.
- Для запуска функции нужно вызвать её по имени: `showMessage()`.

***Локальные переменные***

Переменные, объявленные внутри функции, доступны только внутри неё.

```javascript
function showMessage() {
  let message = 'Привет!';
  alert(message);
}

showMessage();

alert(message); // Ошибка: переменная недоступна
```

***Внешние переменные***

Функция может использовать и изменять переменные, объявленные снаружи.

```javascript
let userName = 'Вася';

function showMessage() {
  userName = 'Петя';
  alert(userName);
}

showMessage(); // Петя
```

Если внутри функции объявлена одноимённая локальная переменная, она перекрывает внешнюю.

**Глобальные переменные** — переменные, объявленные вне всех функций. Они доступны функциям, если не перекрыты локальными переменными.

Рекомендуется использовать глобальные переменные как можно реже, отдавая предпочтение локальным.

***Параметры и аргументы***

**Параметры** — переменные, указанные при объявлении функции.

**Аргументы** — значения, передаваемые функции при её вызове.

```javascript
function showMessage(from, text) {
  alert(from + ': ' + text);
}

showMessage('Аня', 'Привет!');
```

Переданные значения копируются в параметры. Изменение параметра внутри функции не изменяет исходную переменную снаружи.

***Значения параметров по умолчанию***

Если аргумент не передан, параметр получает значение `undefined`.

Чтобы задать значение по умолчанию, используется `=`:

```javascript
function showMessage(from, text = 'Текст не добавлен') {
  alert(from + ': ' + text);
}

showMessage('Аня'); // Аня: Текст не добавлен
```

Значение по умолчанию может быть выражением или вызовом функции. Оно вычисляется только тогда, когда аргумент отсутствует или равен `undefined`.

Если нужно сохранить такие значения, как `0`, `false` и `""`, при выборе значения по умолчанию лучше использовать `??`, а не `||`.

```javascript
function showCount(count) {
  alert(count ?? 'Неизвестно');
}

showCount(0);    // 0
showCount(null); // Неизвестно
showCount();     // Неизвестно
```

***Возврат значения — return***

`return` завершает выполнение функции и возвращает результат в место её вызова.

```javascript
function sum(a, b) {
  return a + b;
}

let result = sum(1, 2); // 3
```

- После `return` функция сразу прекращает работу.
- В функции может быть несколько `return`.
- `return` без значения завершает функцию и возвращает `undefined`.
- Если функция не содержит `return`, результатом также будет `undefined`.

**Важно:** не ставьте перенос строки между `return` и возвращаемым выражением — JavaScript автоматически добавит точку с запятой.

Правильно:

```javascript
return (
  some + long + expression
);
```

***Правила именования функций***

Имя функции должно понятно описывать её действие. Обычно используются глаголы и распространённые префиксы:

- `show...` — показывает что-либо.
- `get...` — получает и возвращает значение.
- `calc...` — вычисляет.
- `create...` — создаёт.
- `check...` — проверяет и обычно возвращает `true` или `false`.

Примеры: `showMessage()`, `getAge()`, `calcSum()`, `createForm()`, `checkPermission()`.

***Одна функция — одно действие***

Функция должна выполнять одну понятную задачу, соответствующую её названию.

Например:
- `getAge()` должна получать и возвращать возраст, а не показывать его через `alert`.
- `checkPermission()` должна проверять разрешение и возвращать результат, а не выводить сообщение.

Если нужны два независимых действия, лучше создать две функции.

***Функции как способ структурирования кода***

Функции делают код понятнее, помогают тестировать и исправлять ошибки. Большую функцию полезно разделять на небольшие.

Даже если функция используется только один раз, её можно создать ради понятной структуры кода.

Например, вместо повторения проверки числа на простоту можно вынести её в отдельную функцию `isPrime()`.

**Итог:**

- Функции позволяют повторно использовать код и избегать дублирования.
- Локальные переменные доступны только внутри своей функции.
- Функции могут обращаться к внешним переменным, но лучше передавать необходимые данные через параметры.
- Параметры — переменные в объявлении, аргументы — значения при вызове.
- Значения параметров по умолчанию задаются через `=`.
- `return` возвращает результат и завершает выполнение функции.
- Если функция ничего не возвращает, результат — `undefined`.
- Имя функции должно отражать её действие.
- Лучше создавать короткие функции, каждая из которых выполняет одну задачу.

# Function Expression

В JavaScript функция является **значением**. Её можно сохранить в переменную, скопировать, передать другой функции и вызвать.

Существует два основных способа создания функций: **Function Declaration** и **Function Expression**.

***Function Expression***

Function Expression (функциональное выражение) — создание функции внутри другого выражения, например присваивания.

```javascript
let sayHi = function() {
  alert('Привет!');
};

sayHi();
```

- Функция создаётся и присваивается переменной `sayHi`.
- Имя после `function` отсутствует — такая функция называется анонимной.
- После выражения присваивания ставится `;`.

***Функция — это значение***

Функцию можно вывести, скопировать в другую переменную или передать как аргумент.

```javascript
function sayHi() {
  alert('Привет!');
}

let func = sayHi; // копируем функцию

func();  // Привет!
sayHi(); // Привет!
```

**Важно различать:**
- `sayHi` — обращение к самой функции.
- `sayHi()` — вызов функции и получение результата её выполнения.

***Функции-колбэки (Callback)***

**Колбэк** — функция, которую передают другой функции в качестве аргумента, чтобы та могла вызвать её позже.

```javascript
function ask(question, yes, no) {
  if (confirm(question)) {
    yes();
  } else {
    no();
  }
}

function showOk() {
  alert('Вы согласились.');
}

function showCancel() {
  alert('Вы отменили выполнение.');
}

ask('Вы согласны?', showOk, showCancel);
```

Колбэки можно объявлять прямо внутри вызова функции, используя Function Expression:

```javascript
ask(
  'Вы согласны?',
  function() {
    alert('Вы согласились.');
  },
  function() {
    alert('Вы отменили выполнение.');
  }
);
```

Такие функции без имени называются **анонимными**.

***Function Declaration и Function Expression: отличия***

**Function Declaration** — обычное объявление функции отдельной конструкцией:

```javascript
function sum(a, b) {
  return a + b;
}
```

**Function Expression** — функция, созданная внутри выражения:

```javascript
let sum = function(a, b) {
  return a + b;
};
```

Главные отличия:

| Function Declaration | Function Expression |
|---|---|
| Отдельное объявление функции | Функция внутри выражения |
| Создаётся до выполнения кода блока | Создаётся при достижении выражения |
| Можно вызвать до объявления | Нельзя вызвать до создания |
| Видна в пределах своей области видимости | Доступна через переменную после присваивания |

Пример Function Declaration:

```javascript
sayHi();

function sayHi() {
  alert('Привет!');
}
```

Работает, потому что Function Declaration обрабатываются до выполнения кода.

Пример Function Expression:

```javascript
sayHi(); // Ошибка

let sayHi = function() {
  alert('Привет!');
};
```

Функция ещё не создана на момент вызова.

***Блочная область видимости***

В строгом режиме Function Declaration, объявленная внутри блока `{}`, доступна только внутри этого блока.

```javascript
if (true) {
  function welcome() {
    alert('Привет!');
  }

  welcome(); // Работает
}

welcome(); // Ошибка
```

Если функцию нужно использовать за пределами блока, можно объявить переменную снаружи и присвоить ей Function Expression:

```javascript
let age = 16;
let welcome;

if (age < 18) {
  welcome = function() {
    alert('Привет!');
  };
} else {
  welcome = function() {
    alert('Здравствуйте!');
  };
}

welcome();
```

***Когда использовать каждый способ***

- **Function Declaration** — предпочтительный вариант в большинстве случаев. Функцию можно вызвать до её объявления, что даёт больше свободы при организации кода.
- **Function Expression** — используется, когда функцию нужно присвоить переменной, передать как аргумент или создать в зависимости от условия.

**Итог:**

- Функции — это значения, которые можно присваивать, копировать и передавать.
- `Function Declaration` — отдельное объявление функции.
- `Function Expression` — функция внутри выражения.
- Function Declaration доступна до своего объявления в пределах области видимости.
- Function Expression создаётся только при достижении её в коде.
- Колбэк — функция, переданная другой функции в качестве аргумента.
- Анонимная функция — функция без имени.
- В большинстве случаев предпочтительнее использовать Function Declaration.

# Стрелочные функции, основы

Стрелочные функции (`Arrow Functions`) — короткий способ создания функций. Особенно удобны для простых действий и колбэков.

***Синтаксис***

```javascript
let func = (arg1, arg2) => expression;
```

Это сокращённая запись:

```javascript
let func = function(arg1, arg2) {
  return expression;
};
```

Пример:

```javascript
let sum = (a, b) => a + b;

alert(sum(1, 2)); // 3
```

**Особенности параметров:**

- Один аргумент — круглые скобки можно опустить:

```javascript
let double = n => n * 2;
```

- Нет аргументов — круглые скобки обязательны:

```javascript
let sayHi = () => alert('Привет!');

sayHi();
```

Стрелочные функции можно использовать как Function Expression, в том числе создавать их в зависимости от условий и передавать в качестве колбэков.

***Многострочные стрелочные функции***

Если функция содержит несколько инструкций, используются фигурные скобки `{}`.

**Важно:** при использовании фигурных скобок для возврата результата необходимо явно указывать `return`.

```javascript
let sum = (a, b) => {
  let result = a + b;
  return result;
};

alert(sum(1, 2)); // 3
```

***Итого***

Стрелочные функции бывают двух видов:

1. **Без фигурных скобок:** `(...args) => expression` — автоматически возвращают результат выражения. Если аргумент один, скобки можно опустить.
2. **С фигурными скобками:** `(...args) => { body }` — позволяют выполнять несколько инструкций. Для возврата результата нужен `return`.

# Особенности JavaScript

***Структура кода***

- Инструкции обычно разделяются точкой с запятой `;`.
- JavaScript поддерживает автоматическую вставку точек с запятой, но она работает не всегда. Поэтому рекомендуется ставить `;` после каждой инструкции.
- После блоков кода `{}` (функций, циклов и т. д.) точка с запятой обычно не нужна.

***Строгий режим***

Для использования современного поведения JavaScript рекомендуется начинать скрипт с директивы:

```javascript
'use strict';
```

- Директива должна находиться в начале скрипта или функции.
- Строгий режим помогает избегать некоторых ошибок и устаревшего поведения.
- Модули и классы автоматически работают в строгом режиме.

***Переменные и типы данных***

Переменные объявляются с помощью:
- `let` — переменная, значение которой можно менять.
- `const` — константа, которую нельзя переназначить.
- `var` — устаревший способ объявления.

Имена переменных могут содержать буквы, цифры, `$` и `_`, но не могут начинаться с цифры.

JavaScript использует динамическую типизацию: переменная может хранить значения разных типов.

**8 типов данных:**

- `number` — числа.
- `bigint` — целые числа произвольной длины.
- `string` — строки.
- `boolean` — `true` или `false`.
- `null` — отсутствие значения.
- `undefined` — значение не задано.
- `object` — сложные структуры данных.
- `symbol` — уникальные идентификаторы.

Оператор `typeof` определяет тип значения, но имеет два известных исключения:

```javascript
typeof null;         // "object" — особенность языка
typeof function(){}; // "function"
```

***Взаимодействие с посетителем***

Основные функции браузера:

- `alert(message)` — показывает сообщение.
- `prompt(question, default)` — запрашивает ввод и возвращает строку или `null` при отмене.
- `confirm(question)` — предлагает подтвердить действие и возвращает `true` или `false`.

Все три функции показывают модальные окна и приостанавливают выполнение кода до ответа пользователя.

***Операторы***

**Арифметические:** `+`, `-`, `*`, `/`, `%`, `**`.

Бинарный `+` может объединять строки. Если один операнд — строка, другой преобразуется в строку:

```javascript
'1' + 2; // '12'
1 + '2'; // '12'
```

**Присваивание:** `=`, `+=`, `*=`, `-=` и другие составные операторы.

**Битовые:** `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`. Работают с числами на уровне отдельных битов.

**Условный оператор:** `условие ? значение1 : значение2`.

**Логические операторы:**
- `&&` — И.
- `||` — ИЛИ.
- `!` — НЕ.

`&&` и `||` используют короткое замыкание и возвращают одно из исходных значений, а не обязательно `true` или `false`.

**Нулевое слияние:** `??` возвращает первое значение, которое не равно `null` или `undefined`.

**Сравнение:**
- `==` — сравнение с преобразованием типов.
- `===` — строгое сравнение без преобразования типов (рекомендуется).
- `!=` и `!==` — неравенство.
- `>`, `<`, `>=`, `<=` — сравнение больше/меньше.

`null` и `undefined` при нестрогом сравнении равны только друг другу. Строки сравниваются посимвольно, остальные типы при необходимости преобразуются в числа.

***Циклы***

В JavaScript есть три основных вида циклов:

```javascript
while (condition) {
  // код
}

do {
  // код
} while (condition);

for (let i = 0; i < 10; i++) {
  // код
}
```

- `while` — проверяет условие перед каждой итерацией.
- `do...while` — сначала выполняет код, затем проверяет условие.
- `for` — объединяет начало, условие и шаг цикла.

Переменная, объявленная через `let` внутри `for`, доступна только в пределах цикла.

- `break` — завершает цикл.
- `continue` — переходит к следующей итерации.
- Метки позволяют управлять вложенными циклами.

***Конструкция switch***

`switch` заменяет несколько проверок `if` и использует строгое сравнение `===`.

```javascript
let age = '18';

switch (age) {
  case '18':
    alert('Совпадение');
    break;

  default:
    alert('Нет совпадения');
}
```

- `case` — вариант для сравнения.
- `break` — завершает выполнение `switch`.
- `default` — выполняется, если совпадений нет.
- Значения разных типов не совпадают: `'18'` и `18` — разные значения.

***Функции***

В JavaScript есть три основных способа создания функций.

**1. Function Declaration** — отдельное объявление:

```javascript
function sum(a, b) {
  return a + b;
}
```

**2. Function Expression** — функция внутри выражения:

```javascript
let sum = function(a, b) {
  return a + b;
};
```

**3. Стрелочная функция:**

```javascript
let sum = (a, b) => a + b;
```

Основные особенности функций:

- Локальные переменные доступны только внутри функции.
- Параметрам можно задавать значения по умолчанию: `function sum(a = 1, b = 2)`.
- `return` возвращает результат и завершает выполнение функции.
- Если `return` отсутствует или не содержит значения, функция возвращает `undefined`.
- Функции можно передавать другим функциям в качестве аргументов — такие функции называются колбэками.
